# Portfolio card template

A short card for a portfolio site, a GitHub profile README or a project list. Markdown is fine here. Keep it under ~120 words. Same honesty rules: no invented numbers.

```markdown
### <Project name>

<One sentence: what it does and for whom. From the README or the user.>

**Stack:** <languages> · <frameworks> · <infra>
**My role:** <from git + user answer, e.g. "Solo project" / "1 of 3 contributors, built the CI/CD" / [role?]>

**Highlights**
- <concrete feature or technical detail>
- <infra / testing / DevOps detail backed by the scan>
- <result from the user, or [metric?]>

**Links:** [Code](<repo URL or [link?]>) · [Demo](<demo URL, or remove>)
```

French version: same structure with « Stack », « Mon rôle », « Points clés », « Liens ».
