# CV section template

Fill the `<...>` fields. Remove a line if you have no data for it. Keep `[metric?]` and `[role?]` placeholders visible when a fact is missing. Plain text only (ATS-friendly).

## English

```
<Project name> — <one-line description>                     <Start month year> – <End month year or "Present">
<Role: e.g. "Personal project" / "Team of 3, backend lead" / [role?]>
Tech: <language 1>, <language 2>, <framework 1>, <framework 2>, <infra tool 1>, <infra tool 2>
- <Action verb> <what> using <tech>, <result or [metric?]>.
- <Action verb> <what> using <tech>, <result or [metric?]>.
- <Action verb> <what> using <tech>, <result or [metric?]>.
- (optional) <bullet 4>
- (optional) <bullet 5>
<Link: github.com/<user>/<repo> or [link?]>
```

## Français

```
<Nom du projet> — <description en une ligne>               <Mois année début> – <Mois année fin ou « Aujourd'hui »>
<Rôle : ex. « Projet personnel » / « Équipe de 3, responsable backend » / [rôle ?]>
Technologies : <langage 1>, <langage 2>, <framework 1>, <outil infra 1>
- <Verbe d'action> <quoi> avec <techno>, <résultat ou [métrique ?]>.
- <Verbe d'action> <quoi> avec <techno>, <résultat ou [métrique ?]>.
- <Verbe d'action> <quoi> avec <techno>, <résultat ou [métrique ?]>.
<Lien : github.com/<user>/<repo> ou [lien ?]>
```
