# Style guide

Write like a developer explaining their work to another developer, not like a marketer.

## Banned phrases (English)

Never use these (or close variants):
- excited to announce, thrilled, delighted to share, humbled
- game-changer, game-changing, revolutionary, groundbreaking, cutting-edge, next-level
- leverage synergies, synergy, paradigm shift, disrupt
- delve, dive deep, unlock, unleash, supercharge, elevate, empower
- seamless, seamlessly, robust and scalable (without proof), world-class, state-of-the-art
- passionate about, rockstar, ninja, guru
- in today's fast-paced world, in the ever-evolving landscape
- I'm proud to say, journey (for a side project), tapestry

## Banned phrases (French)

- ravi de vous annoncer, fier de vous présenter, heureux de partager
- révolutionnaire, disruptif, game changer, incontournable
- tirer parti des synergies, plus-value (vague), à l'ère du numérique
- solution innovante / robuste et scalable (sans preuve), de pointe
- passionné par, plonger dans

## Do this instead

- **Concrete nouns.** "a GitHub Actions workflow that runs 42 tests" beats "an automated quality process".
- **Real numbers only.** Numbers from the scan (files, commits, tests) or from the user. Otherwise `[metric?]`.
- **Plain verbs.** built, fixed, cut, moved, wrote, tested.
- **Short sentences.** One idea per sentence.
- **Specific tech names.** "PostgreSQL", not "a database solution".
- **Show the trade-off or lesson.** Developers trust posts that mention what was hard.

## Emojis

- CV: 0 emojis.
- LinkedIn and X: 0-2 emojis per post. Never one per line. Never as bullet points.

## Self-check questions

- Would a senior developer roll their eyes at any sentence? Rewrite it.
- Can every adjective be replaced by a fact? Do it.
- Is there any claim without a source? Remove it.
