## Bullet formula

**Action verb + what you built or changed + tech used + result or impact.**

- Start with a strong past-tense verb (French: infinitive or past participle, stay consistent).
- Name the real tech from the scan (frameworks, infra), not generic words like "modern tools".
- End with the result. If the user gave no result, end with `[metric?]` or with a concrete scope fact from the scan (e.g. "across 3 services", "with 40 automated tests").
- One line, at most two. About 15-30 words.

## How many bullets

- 3 to 5 bullets per project.
- Order: the most impressive and best-supported bullet first.
- Cover different angles: feature work, infra/DevOps, quality (tests, CI), collaboration (only if the user confirmed it).
- Do not repeat the same tech in every bullet.

## ATS-friendly format

Applicant Tracking Systems parse plain text. So:
- No tables, columns, text boxes, icons or emojis.
- Plain bullets (`-` or `•`).
- Standard section names: "Projects" / "Projets".
- Write tech names in full and in their usual spelling: "Kubernetes" (you can add "K8s" once), "GitHub Actions", "PostgreSQL".
- Put the key tech words from the target job in the bullets, but only if the repo really uses them.
- Dates as "Jan 2024 – Mar 2024" or "01/2024 – 03/2024". Use git first/last commit dates only as a hint; ask if unsure.

## Good and bad examples

Bad: "Worked on a web app using various technologies."
- No verb strength, no tech, no result.

Bad: "Built a scalable platform used by 10,000 users, improving performance by 300%."
- Invented numbers. Never do this.

Good: "Containerized a Flask API and React front end with Docker Compose and added a GitHub Actions pipeline that runs pytest on every push."

Good with placeholder: "Automated deployment to Kubernetes with Helm charts, cutting release time from [metric?] to [metric?]."

## Action verbs (English)

- Build: built, developed, implemented, created, shipped, prototyped
- Design: designed, architected, modeled, structured
- Improve: optimized, refactored, reduced, sped up, simplified, migrated
- Automate / DevOps: automated, containerized, deployed, provisioned, orchestrated, configured, monitored
- Quality: tested, validated, secured, hardened, debugged, fixed
- Data: integrated, parsed, processed, analyzed, visualized
- Team: collaborated, reviewed, documented, mentored, coordinated

## Action verbs (French)

Use one form for all bullets: infinitive ("Développer") or past participle ("Développé"). The past participle is common on French CVs.

- Construire : développé, conçu, implémenté, créé, livré, prototypé
- Concevoir : architecturé, modélisé, structuré
- Améliorer : optimisé, refactorisé, réduit, accéléré, simplifié, migré
- Automatiser / DevOps : automatisé, conteneurisé, déployé, provisionné, orchestré, configuré, supervisé
- Qualité : testé, validé, sécurisé, renforcé, débogué, corrigé
- Données : intégré, analysé, traité, visualisé
- Équipe : collaboré, relu (code review), documenté, encadré, coordonné

French example: « Conteneurisé une API Flask et un front React avec Docker Compose, et mis en place une CI GitHub Actions qui lance pytest à chaque push. »
